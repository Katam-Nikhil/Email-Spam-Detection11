SMALL SPAM DETECTION WEBSITE

Files:
- index.html: webpage structure
- style.css: webpage design
- script.js: simple message checking logic

How to use:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it with Live Server in VS Code.

This is a small browser-only demonstration using common spam keywords.
It does not use Flask or a trained machine-learning model.
It can be hosted on GitHub Pages.
